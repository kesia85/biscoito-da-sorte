# Biscoito da Sorte

Um projeto simples e interativo, desenvolvido para praticar HTML, CSS e JavaScript. 

## Sobre o projeto

O Biscoito da Sorte é uma página interativa que apresenta uma mensagem aleatória quando o usuário clica no biscoito.

O projeto começou com o desejo de criação de um App atrativo e interessante, pensando em uma perspectiva de usuário. O que alguém gostaria de fazer ou experimentar em um App? Seria legal um App de Biscoito da Sorte.

O projeto foi desenvolvido como parte da minha prática de programação e faz parte da construção do meu portfólio.

## Funcionalidades

* Sorteio de uma mensagem aleatória entre 20 mensagens.
* Exibição da mensagem diretamente na página.
* Efeito visual ao clicar no biscoito.
* Bloqueio de novos sorteios por 30 minutos após o clique.
* Layout adaptado para telas menores.

## Tecnologias utilizadas

* CSS3
* JavaScript
